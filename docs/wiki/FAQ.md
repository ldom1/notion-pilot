# FAQ

**Is Telegram required?**  
No. The product story is Notion + Claude Code with human approval. Telegram (and email/Discord) are optional adapters — see [[Capture-channels]].

**Where does my data live?**  
See the canonical block on [[Home]] (**Where your data goes**). EU hosting is a Notion Enterprise option for data stored in Notion; it does not cover AI processing by your assistant's provider.

**Will the AI write garbage into my CRM?**  
Dry-run / preview is the default. Nothing reaches Notion until you approve.

**French companies only?**  
Firmographic auto-enrichment targets French open data (SIRENE, filings). Companies outside France can be stored; they are not auto-enriched.

**Where is the live site?**  
Canonical: [https://notion-pilot.com/](https://notion-pilot.com/). `notion-pilot.dombot.tech` redirects there.

**How do I install the skills?**  
[notion-pilot-powers](https://github.com/ldom1/notion-pilot-powers) — two Claude Code plugin commands (not the old `notion-crm@notion-pilot` marketplace).
