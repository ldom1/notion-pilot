# promotion/video — the landing-page films

Three silent 16:9 films. Only `notion-pilot-pipeline` is embedded on the landing page
(after the decay beat, played slightly under real time). The other two remain in this
catalog: HITL is told by the assistant preview; collaboration is native Notion
and is named in the EU/Enterprise band.

They are HTML compositions rendered to MP4 by [HyperFrames](https://hyperframes.heygen.com),
authored on the same token layer as the site (`web/frontend/src/styles/tokens.css`), so a
change to the design system can be carried into the films rather than reinvented in them.

| Project                 | Subject                                          | Length | On the page |
| ----------------------- | ------------------------------------------------ | ------ | ----------- |
| `notion-pilot-pipeline` | email → agent → approved diff → Notion → KPIs    | 21s    | yes         |
| `notion-pilot-agent`    | `confirm=false` is the default; the four rules    | 16s    | no          |
| `notion-pilot-collab`   | three people dictating into one shared workspace | 19s    | no          |

Each project holds its `BRIEF.md` (confirmed intent and beat sheet) and `index.html` (the
composition). `notion-pilot.json` is the brand profile the `website-to-hyperframes-core`
skill reads.

## Layout

```
promotion/video/
├── notion-pilot.json            brand profile (palette, type, tone, CTA)
├── package.json                 pins the hyperframes CLI for every project here
└── hyperframes/
    ├── sync-shared.sh           copies _shared/ into each project's assets/
    ├── _shared/
    │   ├── np.css               the films' design system — mirrors tokens.css
    │   ├── fetch-fonts.sh       re-downloads the localised woff2 files
    │   └── fonts/               Archivo + IBM Plex Mono, latin + latin-ext
    └── notion-pilot-*/          one project per film
        ├── BRIEF.md             intent, angle, beat sheet
        ├── index.html           the composition
        └── assets/              generated by sync-shared.sh — not committed
```

`assets/`, `out.mp4` and `snapshots/` are generated and gitignored. The delivered MP4s and
their poster frames live in `web/frontend/public/film/` and **are** committed, because the
app serves them at `/film/<slug>.mp4`.

## Working on a film

```bash
cd promotion/video && npm install          # once — installs the hyperframes CLI
HF=$PWD/node_modules/.bin/hyperframes

./hyperframes/sync-shared.sh               # after editing _shared/np.css

cd hyperframes/notion-pilot-pipeline
$HF check                                  # lint + runtime + layout + motion + contrast
$HF snapshot --at 1.5,6.5,11.8,15.8 --no-end   # eyeball the beats before rendering
$HF render --quality high --output out.mp4
```

`check` must report **0 errors** before a render: a lint error silently switches off the
layout and contrast audits, so a "clean" run with errors present has verified nothing.

## Publishing a re-render

```bash
cd /path/to/notion-pilot
ffmpeg -y -i promotion/video/hyperframes/<slug>/out.mp4 \
  -c copy -movflags +faststart web/frontend/public/film/<slug>.mp4
# poster frame — pick a beat that shows the film's subject, not a cross-fade
ffmpeg -y -ss 11.8 -i promotion/video/hyperframes/<slug>/out.mp4 \
  -frames:v 1 -q:v 4 web/frontend/public/film/<slug>.jpg
```

`+faststart` moves the MP4 index to the front so playback starts before the whole file has
downloaded. The poster is what a reader sees when autoplay is blocked or they have asked
the OS for reduced motion, so it has to stand on its own.

## House rules for these films

- **No audio.** They autoplay muted inline next to prose; a sound track would be dead
  weight in the MP4 and a nuisance if it ever unmuted.
- **Colour only on data.** White stock, achromatic greys, near-black as the only brand
  colour. Won / stale / lost are the only hues, exactly as on the site.
- **The figures must match the page.** Every record, stage, value and name in a film also
  appears in `web/frontend/src/pages/Landing.tsx`. If one moves, both move.
- **Full measure on the page.** These frames are tables and tool logs. Half-width columns
  halve the type inside them too and the film stops being readable.

## Reinstalling the authoring skills

`npx skills add heygen-com/hyperframes` installs the HyperFrames skill pack into
`.agents/skills/` (symlinked into `skills/` and `.claude/skills/`). The pack itself is
gitignored; `skills-lock.json` pins the versions, so reinstall rather than commit it.
